# Oferta Certa 🏷️

Landing page do **Oferta Certa**, comunidade de ofertas e promoções em beleza, moda e casa.

🔗 **[oferta-certa.racka.com.br](https://oferta-certa.racka.com.br)**

## Sobre

Página de apresentação da comunidade, com convite para o grupo VIP. Foco em leveza e conversão:

- ⚡ Site 100% estático — um único HTML, sem frameworks, sem build e sem dependências externas
- 🎯 Botão de chamada com animação de pulo e brilho
- 💬 Notificações animadas de novas participantes em tempo real na tela
- 🔢 Contador de vagas dinâmico
- 📱 Layout mobile-first, responsivo
- 🖼️ Imagens em WebP e fonte auto-hospedada — carregamento quase instantâneo

## Estrutura

```
index.html    página completa (HTML + CSS + JS)
assets/       imagens, ícone e fontes
```

## Rodando localmente

Não precisa de nada além de um servidor estático:

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```
